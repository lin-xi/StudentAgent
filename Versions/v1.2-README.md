# v1.2 版本更新说明

## 新增功能

### 1. 用户登录注册系统

#### 功能特性
- **注册**: 用户名 + 密码（8-20 位英文字母和数字组合）
- **登录**: 用户名 + 密码 + 滑动验证码
- **Cookie 认证**: 登录成功后设置 3 个月有效期的 session cookie

#### 滑动验证码机制
1. 后端生成 0-1 的随机目标值
2. 前端拖动滑块，实时显示当前值
3. 前端预验证：允许 0.02 的误差范围
4. 登录时携带 captcha_value 进行后端验证

### 2. 后端数据存储

#### 技术栈
- **后端框架**: Python/FastAPI
- **数据库**: MySQL
- **连接方式**: 连接池（mysql-connector-python）

#### 数据库表结构

| 表名 | 说明 |
|------|------|
| users | 用户表（id, username, password_hash） |
| courses | 课程表（id, subject, grade, syllabus_json） |
| progress | 学习进度表（关联 user 和 course） |
| questions | 问题表（存储 AI 生成的题目） |
| mistakes | 错题表（记录用户做错的题目） |

#### 数据库配置
```

```

## API 端点

### 认证相关
| 端点 | 方法 | 说明 |
|------|------|------|
| /api/captcha | GET | 获取滑动验证码目标值 |
| /api/register | POST | 用户注册 |
| /api/login | POST | 用户登录 |
| /api/logout | POST | 用户登出 |
| /api/me | GET | 获取当前用户信息 |

| 端点 | 方法 | 说明 |

| /api/evaluate | POST | 评估答案 |

## 部署步骤

### 1. 安装依赖
```bash
cd backend
pip install -r requirements.txt
```

### 2. 初始化数据库
```bash
python init_db.py
```

### 3. 启动后端
```bash
./start_backend.sh
# 或
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

### 4. 启动前端
```bash
cd frontend
npm run dev
```

## 注意事项

1. **密码安全**: 密码使用 SHA256 哈希存储，建议在生产环境使用 bcrypt
2. **会话管理**: 当前 session_token 存储在 cookie 中，服务端会话存储待实现
3. **验证码存储**: 滑动验证码临时存储在内存中，生产环境建议使用 Redis
4. **数据库连接**: 使用连接池管理数据库连接，池大小为 5
